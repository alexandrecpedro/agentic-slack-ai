# 0022 · UUID v7 as ID, generated in the application

Our database tables for both the chat database and the agents database use UUID v7 as IDs, generated in the application. The rationale is to be defined.

Discarded: database-generated `bigint`; UUID v4.
Accepted cost: 16 bytes per ID, double that of a `bigint`; other costs to be defined.
